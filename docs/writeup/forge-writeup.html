Forge is a VS Code extension whose agent loop runs on TrueForge. It finds the right code itself, changes several files you never named, tests its own work, and lets you accept or reject every hunk before anything is saved — and it keeps working when the model fails. We built it for free-tier models, so every choice aims at fewer, smaller, safer requests.

3 Architecture on TrueForge

The extension is a client of a local TrueForge agent: it opens sessions and turns through the TypeScript SDK and renders the streamed events. The editor's abilities are exposed as MCP tools, so the agent — not the extension — decides what to read, change and run. TrueForge makes every model call.

How one request flows

1Context

BM25 and the RepoMap code graph pick files and whole functions under a token budget — before any model call.

2Agent loop

TrueForge runs the model, which calls Forge's MCP tools to search, read, look up the graph and stage edits.

3Verify

Edits stay in memory. Forge runs the relevant tests in a sandboxed copy and reports only new failures.

4Review

submit_for_review needs TrueForge approval; it opens the diff with Accept / Reject on every hunk.

5Apply · Undo

Accepted hunks are saved; files changed meanwhile are refused; one click undoes the change.

4 How context is selected

A budgeted context pack, built from text ranking and the code graph, shown to the user file by file with the reason it was chosen.

  1. Rank text with BM25 (length-normalised). Files that define a named identifier rank higher; words like "test" or "documented" choose file roles.
  2. Add the code graph. The RepoMap focus symbol must sit in the best text-ranked file; its callers, callees and tests join. Every caller edge is checked against its call-site line.
  3. Pick by role — the best implementation, test and docs file. Extra files need graph or naming evidence, not just shared words.
  4. Excerpt whole functions using RepoMap's parsed symbol ranges, until the budget is spent.

7 Tools used

  • AI coding assistants: Claude Code (Anthropic), OpenAI Codex.
  • Harness: TrueForge 0.185.1 (local) and its TypeScript SDK; MCP TypeScript SDK; RepoMap 1.9.0.
  • Testing: VS Code Extension API with 8 tests in a real editor; 21 offline tests including a fake TrueForge; pytest; uv; macOS sandbox-exec.

8 Limitations · next month

  • Free tiers are the ceiling. Successful Task B runs took 25–65 model calls; some stopped when every provider hit its quota at once (partial work is then offered for review, flagged incomplete).
  • The code graph is static: each edge is verified at its call site, but dynamic calls can be missed.
  • The command sandbox is macOS-only; Windows is untested.

Next month: persistent indexes for huge repos, Linux sandboxing, a task benchmark to tune ranking, and TrueForge PRs for built-in model fallback.
