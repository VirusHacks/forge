Why build it this way? True Forge runs the agent loop. Our engineering goes into what that loop sees and touches. Graph engineering: Forge maps the repo into a Repo Map code graph of symbols, callers and tests, verifies every edge at its call site, and packs the right neighbourhood into a token budget before the first model call. Then nine M C P tools we built around it: batched search and read, graph lookup, staged edits, sandboxed commands, and an approval-gated submit. Together, that took a three-file task from eighty-five model calls to about twenty-five.
